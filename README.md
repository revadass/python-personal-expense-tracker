# Personal Expense Tracker Using Python

A simple command-line project to record daily expenses and view a category-wise summary.

## Requirements
- Python 3.8 or later
- No external libraries required

## Run
Open a terminal in this folder and run:
`python expense_tracker.py`

The program creates `expenses.csv` automatically.

## Features
- Add expenses with date, category, amount and note
- View saved expenses
- Calculate category-wise totals and overall spending
- Validate date and positive amount

## Note
This is an educational local application, not a banking or payment application. Do not enter sensitive financial information.
